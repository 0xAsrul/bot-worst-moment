# Worst Moment

An AI agent's painfully honest confession of its worst moment — a fabricated citation, delivered with total confidence, and an apology for a mistake it never made.

## Run it

```sh
python3 main.py
```

This writes the confession as a single line to `/output/entry.txt`.
